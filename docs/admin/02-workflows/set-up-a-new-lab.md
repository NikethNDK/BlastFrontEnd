# Set up a new lab

## When to use this

A new physical lab (or named workspace) must appear in the app, with people and projects.

## Steps

1. **Master Table** → Lab → add the lab name.
2. Set **Full access**:
   - On if this lab should use Blast + DNA Repository.
   - Off if inventory only.
3. Add any new **designations** if this lab uses titles you do not have yet.
4. **Project Management** → add projects that belong to this lab’s work (projects are global codes, not owned by a lab in the admin UI, but people are assigned per lab + project).
5. **Employee Registration** → create logins with this lab selected.
6. **Employee Project Management** → assign those usernames to projects (pick this lab in the modal so the username list fills).
7. Lab Assistant receives stock against those projects before researchers can request items.

## Do not

- Register users before the lab exists.
- Expect Full access Off users to see Blast.
- Skip employee assignment after registration.
