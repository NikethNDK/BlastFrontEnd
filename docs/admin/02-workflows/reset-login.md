# Reset a login password

## Admin reset (any user)

1. Sidebar **Password Reset**.
2. Search → key icon.
3. Type the new password → **Reset password**.
4. Tell the user. Old password will not work.

Details: [Password Reset](../01-modules/password-reset.md).

## Self-service (not Admin)

Manager, Lab Assistant, and Researcher: **Change Password**. Username is their login username (read-only). Toast: “Password changed successfully!”

## After reset

They must use the **new** password on the login page. Passwords are plain text: spelling, spaces, and capital letters must match.

If login still fails: [login-and-passwords.md](../04-troubleshooting/login-and-passwords.md).
